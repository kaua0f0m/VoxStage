# VoxStage

Local karaoke for Windows, Android phones and Android / Google TV. The same
Android application detects a TV and adapts its interface and remote controls.
The VX symbol is the compact logo; the product name remains VoxStage.

## Sobre o projeto

O VoxStage foi inteiramente vibecodeado. Pull requests são bem-vindos se você
tiver uma ideia para melhorar o projeto — vibecodeada ou não.

## Structure

| Path | Purpose |
| --- | --- |
| Root HTML/JS/CSS | Shared player, lyrics editor, import UI and phone remote |
| server.py | Windows library, downloads, MVSep and LAN transfers on port 8000 |
| local_audio_runner.py and requirements files | Optional desktop AI processing |
| native-app/src-tauri/src | Native Rust host and Android service bridge |
| native-app/src-tauri/gen/android | Android project with custom Kotlin integrations |
| native-app/scripts | Development, builds, packaging and logo generation |
| native-app/assets, branding, fonts | Icons, logos and locally bundled Nunito |

The Android project is committed despite its `gen` name: it contains the camera,
media notification and yt-dlp integrations. Do not regenerate it with `android
init` over these customizations. Machine paths are regenerated by
`prepare-android.mjs`, not committed.

## Development (Windows)

Install Node.js, Rust with the MSVC toolchain / C++ Build Tools, and Python 3.13.
Then, from this folder:

```powershell
npm ci --prefix native-app
py -3.13 -m pip install -r requirements-build.txt
npm run dev
```

Windows playback uses WebView2. AI tools are optional and desktop only; Android
and TV use the online services without bundling local AI models.

## Build Windows

```powershell
npm run build:windows
```

Output: `releases/V1.0.2/VoxStage-1.0.2-Windows-x64.zip`. Extract the full folder and
open `VoxStage.exe` or `Abrir VoxStage.vbs`. The server runs without a terminal.
Node and Python are included in this portable package. The packager needs the
Node distribution's LICENSE beside node.exe; `VOXSTAGE_NODE_LICENSE` can override
that path. `VOXSTAGE_FFMPEG` can select an existing FFmpeg executable; otherwise
imageio-ffmpeg supplies it.

## Build Android / Google TV

Install Android Studio / JDK, SDK platform 37, build tools 36.0.0 and NDK
27.2.12479018. Set JAVA_HOME, ANDROID_HOME and NDK_HOME if using nondefault paths.

```powershell
npm run build:android
```

Builds target ARM64 only, for both Android phones and Google TV.
Public release: `releases/V1.0.2/VoxStage-1.0.2-Android-GoogleTV-ARM64.apk`.
Output: `native-app/src-tauri/gen/android/app/build/outputs/apk/arm64/release/app-arm64-release.apk`.
The 1.0.1 release at `releases/V1.0.1/VoxStage-1.0.1-Android-GoogleTV.apk`
is the last universal APK with ARM32 and ARM64. VoxStage detects TV mode.

The current release signing configuration uses the developer's local debug key.
Keys are not in this repository. Keep your existing key to update installed
builds without uninstalling; configure your own release signing before store
publication.

## Branding

The Nunito font and its OFL license are bundled in `fonts/`. To regenerate PNG,
SVG, ICO and Android assets:

```powershell
npm install
npx playwright install chromium
npm run brand
```

## Private data

Songs, keys, downloaded files, models, dependencies and compiled binaries are
ignored by Git. Development data lives in `native-app/dev-data/`; portable
Windows uses an existing native library beside the project or the application
data directory. `VOXSTAGE_DATA_DIR` can select another library. Android data
stays in app storage; uninstalling removes it.

See `MIGRACAO.md` for moving this local workspace. Online services require the
user's own connection and MVSep key. See `THIRD_PARTY_NOTICES.md` for bundled
dependencies. Choose a project license before offering permission to reuse the
VoxStage code; third-party licenses remain applicable.
