# VoxStage

Local karaoke for Windows, Android phones and Android / Google TV. The same
Android application detects a TV and adapts its interface and remote controls.

# Features

Plataformas
- [x] Aplicativo portátil para Windows.
- [x] Aplicativo para Android.
- [x] Suporte a Android TV e Google TV, com navegação pelo controle remoto.
- [x] Interface em português e inglês.

Biblioteca e reprodução
- [x] Importação de músicas e arquivos de áudio locais.
- [x] Reprodução de músicas completas ou separadas em instrumental, vocais principais e backing vocals.
- [x] Controle independente do volume de cada faixa; músicas completas usam um único controle de volume.
- [x] Busca na biblioteca, favoritos e músicas recentes.
- [x] Edição de título, artista, capa e fundo.
- [x] Exclusão e ocultação de músicas da biblioteca.
- [x] Busca de capas, com aplicação como capa, fundo ou ambos.
- [x] Imagens e vídeos sem áudio como fundo da apresentação.
- [x] Reprodução, pausa, avanço, retrocesso e seleção da posição na música.
- [x] Exibição do nome completo de arquivos em um overlay no Android.

Letras e apresentação
- [x] Busca de letras pelo LRCLIB.
- [x] Inserção e edição de letras, incluindo letras sincronizadas em LRC.
- [x] Sincronização manual por linha e por palavra.
- [x] Ajustes de tempo e duração das linhas.
- [x] Destaque da linha e da palavra em reprodução.
- [x] Exibição de letras de backing vocals. (mediante calibração)
- [x] Marcação de pausas vocais e indicação do tempo restante. (mediante calibração)
- [x] Censura de palavras selecionadas, com tratamento visual e silenciamento dos vocais.
- [x] Modo de apresentação em tela cheia.
- [x] Botões para ocultar os controles e sair da apresentação.
- [x] Ocultação automática dos controles no PC após cinco segundos sem movimento, preservando sua exibição enquanto o mouse estiver sobre eles.
- [x] Personalização de cores, tamanho das letras e aparência da apresentação.

Downloads e processamento
- [x] Busca no YouTube Music, com opção de incluir resultados do YouTube.
- [x] Importação por link do YouTube.
- [x] Download de áudio com yt-dlp integrado.
- [x] Download de vídeos no Windows.
- [x] Separação na nuvem pelo MVSEP usando a chave API do usuário.
- [x] Separação pelo MVSEP de músicas completas já salvas na biblioteca.
- [x] Separação local no Windows, com instalação dos modelos necessários. (experimental)
- [x] Orientações para obter e cadastrar uma chave MVSEP.
- [x] Tela de envios e processamentos em progresso, permitindo sair do formulário e voltar depois.
- [x] Notificações de processamento no Android.

Celular, computador e TV
- [x] Conexão entre dispositivos na mesma rede por QR code ou link.
- [x] Leitura de QR code pela câmera ou por uma imagem no Android.
- [x] Controle remoto da reprodução pelo celular.
- [x] Envio de músicas do Android para o computador ou a TV.
- [x] Transferência de músicas do computador para o Android.
- [x] Envio da chave MVSEP do Android para a TV.
- [x] Configuração inicial da TV pela tela de conexão ao celular.
- [x] Fila de pedidos com aceitação automática de músicas já disponíveis.
- [x] Transferência automática quando a música existe apenas no celular.
- [x] Aprovação para pedidos de músicas ausentes nos dois dispositivos, que podem exigir processamento e gastar créditos.

## Sobre o projeto

O VoxStage foi inteiramente vibecodeado. Pull requests são bem-vindos se você
tiver uma ideia para melhorar o projeto — vibecodeada ou não.

## Structure

| Path | Purpose |
| --- | --- |
| Root HTML/JS/CSS | Shared player, lyrics editor, import UI and phone remote |
| server.py | Windows library, downloads, MVSep and LAN transfers on port 8000 |
| local_audio_runner.py and requirements files | Optional desktop AI processing |
| native-app/src-tauri/src | Native Rust host and Android service bridge |
| native-app/src-tauri/gen/android | Android project with custom Kotlin integrations |
| native-app/scripts | Development, builds, packaging and logo generation |
| native-app/assets, branding, fonts | Icons, logos and locally bundled Nunito |

The Android project is committed despite its `gen` name: it contains the camera,
media notification and yt-dlp integrations. Do not regenerate it with `android
init` over these customizations. Machine paths are regenerated by
`prepare-android.mjs`, not committed.

## Development (Windows)

Install Node.js, Rust with the MSVC toolchain / C++ Build Tools, and Python 3.13.
Then, from this folder:

```powershell
npm ci --prefix native-app
py -3.13 -m pip install -r requirements-build.txt
npm run dev
```

Windows playback uses WebView2. AI tools are optional and desktop only; Android
and TV use the online services without bundling local AI models.

## Build Windows

```powershell
npm run build:windows
```

Output: `releases/V1.0.2/VoxStage-1.0.2-Windows-x64.zip`. Extract the full folder and
open `VoxStage.exe` or `Abrir VoxStage.vbs`. The server runs without a terminal.
Node and Python are included in this portable package. The packager needs the
Node distribution's LICENSE beside node.exe; `VOXSTAGE_NODE_LICENSE` can override
that path. `VOXSTAGE_FFMPEG` can select an existing FFmpeg executable; otherwise
imageio-ffmpeg supplies it.

## Build Android / Google TV

Install Android Studio / JDK, SDK platform 37, build tools 36.0.0 and NDK
27.2.12479018. Set JAVA_HOME, ANDROID_HOME and NDK_HOME if using nondefault paths.

```powershell
npm run build:android
```

Builds target ARM64 only, for both Android phones and Google TV.
Public release: `releases/V1.0.2/VoxStage-1.0.2-Android-GoogleTV-ARM64.apk`.
Output: `native-app/src-tauri/gen/android/app/build/outputs/apk/arm64/release/app-arm64-release.apk`.
The 1.0.1 release at `releases/V1.0.1/VoxStage-1.0.1-Android-GoogleTV.apk`
is the last universal APK with ARM32 and ARM64. VoxStage detects TV mode.

The current release signing configuration uses the developer's local debug key.
Keys are not in this repository. Keep your existing key to update installed
builds without uninstalling; configure your own release signing before store
publication.

## Branding

The Nunito font and its OFL license are bundled in `fonts/`. To regenerate PNG,
SVG, ICO and Android assets:

```powershell
npm install
npx playwright install chromium
npm run brand
```

## Private data

Songs, keys, downloaded files, models, dependencies and compiled binaries are
ignored by Git. Development data lives in `native-app/dev-data/`; portable
Windows uses an existing native library beside the project or the application
data directory. `VOXSTAGE_DATA_DIR` can select another library. Android data
stays in app storage; uninstalling removes it.

See `MIGRACAO.md` for moving this local workspace. Online services require the
user's own connection and MVSep key. See `THIRD_PARTY_NOTICES.md` for bundled
dependencies. Choose a project license before offering permission to reuse the
VoxStage code; third-party licenses remain applicable.

Pontuação mais compacta no Android em paisagem, filtro do microfone ajustável durante o canto e motor JavaScript do YouTube integrado no Android/Google TV. Recomendo fones para evitar que a música encubra sua voz ou conte como canto. Veja os ajustes e a nota sobre a experiência no celular no [changelog](CHANGELOG.md).

## Novidades da 1.1

- Pontuação de canto com notas sustentadas, microfone local, referências por ambos os vocais ou pelas três trilhas, início automático da música e histórico local.
- Pontos cumulativos: 1.000 por nota acertada, sem perder pontos. Estrelas em 9/18/27/36/45%; cinco estrelas douradas em 55%.
- Velocidade de 0,75× a 1,25× e tom de −4 a +4 semitons em tempo real, com letras e pontuação acompanhando os ajustes.
- Celular conectado como microfone do PC/TV, além da captura nativa no Android. Essa integração ainda precisa de avaliação em aparelhos físicos.
- Faixa de notas adaptada ao Android vertical/horizontal e à TV, com letras opcionais e controles compactos.
- Preenchimento automático pelo YouTube, correções de metadados do YouTube Music, melhor reconhecimento do instrumental no MVSEP e botão Acoplar arquivos.
- Busca automática de letras com recuperação de falhas temporárias; pausas instrumentais preservam o texto e respeitam a sincronização dos trechos cantados.
- Aba Sobre com logo, versão, autor, inspiração e atribuições; links abrem o navegador e as configurações ficam mais organizadas.

O [changelog](CHANGELOG.md) reúne as novidades das versões públicas.
